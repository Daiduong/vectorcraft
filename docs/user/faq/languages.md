---
title: Which languages does VectorCraft speak?
description: The interface languages VectorCraft ships with.
order: 30
verified: 0.9.0
---

The interface speaks English, German, Japanese, Traditional Chinese, Simplified Chinese, Spanish, French, Italian, Russian and Ukrainian. Czech and Brazilian Portuguese can be chosen too, but are only partly translated, so some text stays in English. Hungarian was added after 0.9.0 and is not in a release yet. To switch, choose **Edit** › **Preferences…** › **User Interface** and set **Language** (on macOS, **VectorCraft** › **Language**).
