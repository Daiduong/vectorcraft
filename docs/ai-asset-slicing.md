# AI-assisted asset slicing

The desktop app can find reusable buttons, icons, panels and screens in imported artwork using SVG geometry and an Ollama vision model. Open a document, then choose **Layers panel menu → Slice Artwork with AI…** (command `ui.sliceWithAI`).

1. Run Ollama and install a vision model yourself, for example `ollama pull qwen2.5vl:3b`. The app does not download models. The default endpoint is `http://localhost:11434/api/chat` and the default model is `qwen2.5vl:3b`. The server URL, model and name language are the same Ollama connection used by Name Layers with AI. `curl` must be available. Plain `http://` is accepted only for a loopback host (`localhost`, `127.0.0.0/8`, or `::1`). A remote server must use `https://`.
2. Choose the model and name language. Enable **Selection Only** to detect elements in the selected artwork. Otherwise the preview covers the document artwork bounds.
3. **Ignore sheet background** is enabled by default. It excludes a bottommost solid rectangular backdrop matching an artboard and enclosing at least two other objects. It only changes the temporary preview/export copy; disable it to retain the backdrop. Clipped or styled containers are never searched for backdrops.
4. **Ignore external shadows** is also enabled by default. It excludes only a narrowly recognized flat rear shadow: a neutral grey, translucent Multiply path/compound behind a taller body, anchored at its bottom edge and extending well beyond its width. Small shadows, coloured Multiply artwork, opaque elements, broad translucent panels and clipped/styled containers are retained. Turn this off when the long shadow is part of the intended asset. Bounds, model previews and direct SVG/PNG exports all use the same temporary copy; the original document stays intact.
5. Click **Play**. VectorCraft separates spatial islands of sibling artwork using painted bounds. Overlapping parts stay together, while clipped, masked, styled or translucent containers remain whole. Small detached captions stay with a dominant control. Tiny bounds overlaps (up to 2% of the smaller part) are tolerated so touching shadows do not join adjacent assets. The model names each region from a separate white-backed preview (at most 512 pixels on its longest side); it never supplies coordinates. Each preview is sent to the configured server. The first request also includes a sheet overview and may return a collection title for the automatic export folder; this does not add a model request. A remote endpoint receives those previews only over HTTPS. Inference runs off the UI thread. The preview appears before naming finishes, and ready regions arrive one at a time with progress. Diagonal stripes move inside the completed part of the bar, with a small active cap while waiting for the first response. Pause holds the stripes still; completion shows a plain full bar. Explicit Processing, Paused and Completed states show whether work is active or finished. **Pause** preserves ready regions and lets the current request finish; no next request starts until **Play**. The current request can take up to 120 seconds.
6. Review the numbered boxes over the preview. Edit names and document-coordinate X/Y/width/height fields; uncheck unwanted regions. Names are validated; bounds come from the vector artwork; suggestions are not a guarantee that an element is correctly detected.
7. On pause, ready regions can already be exported or created as slices while the current request finishes. The destination defaults immediately to `~/Pictures/VectorCraft/<document name>`; an optional AI collection title updates it only before any manual path edit or successful export. Choose a destination folder and **SVG** or **PNG**, then **Export Regions**, or click **Create Slices** to add the checked regions as ordinary editable document slices in one undo step. Export and slice creation are separate actions. Export keeps every checkbox unchanged and does not disable Create Slices. Created slices are marked and skipped by later Create actions until Start Over. Exports have separate receipts per destination, format, resolution and appearance; identical repeated exports are skipped, while new ready regions are exported on the next batch. Manual edits and exclusions remain. New ready rows are checked. Stable region-number prefixes allow successive exports into the same folder, including equal names. **Create folder if missing** is enabled by default; disable it to require an existing folder. Existing files are never overwritten. Closing the dialog pauses the job and keeps its checkpoint in the current app session, including the in-flight response; reopen the dialog and press Play to continue. **Start Over** clears proposals and starts afresh without undoing slices or deleting exported files. Checkpoints are not restored after restarting the app.

For detected regions, direct **Export Regions** and the model preview isolate the source group or all members of its spatial component with their original ancestors, clipping and appearance. This prevents neighbouring objects from entering a crop even when a compound path has conservative bounds; the rectangle may still include transparent margins. Manually supplied regions without source IDs use ordinary rectangular cropping. **Create Slices** always creates ordinary rectangular document slices, without detaching or isolating source objects.

The default **Match preview (SVG embeds an image)** mode embeds a transparent PNG rendered by VectorCraft inside an SVG viewport. This matches the native preview in browsers and system viewers, including complex blending, but the SVG content is a raster image rather than editable paths. Increase the scale for higher resolution; the raster pixel limit also applies to this mode. Turn this option off for editable SVG vectors, groups, clipping and effects through the existing SVG writer. Other viewers may render complex blends differently in this editable mode. Artwork outside each crop is pruned where it can be removed without breaking group appearance; paths crossing a crop stay whole and the SVG viewport clips them. PNG exports use transparent backgrounds at the chosen scale. For manual regions without source IDs, both formats crop everything inside the rectangle, so overlapping art and other painted backgrounds remain. This is region extraction, not semantic background removal or automatic reparenting of paths. Complex masks retain their original hierarchy.

Export names have a numeric prefix and a sanitized element name. Existing files are never replaced. A failed write rolls back files created by that batch. Detection also bounds traversal to 32 levels and 4096 siblings per container; narrow the selection for more complex sheets. Batches are limited to 64 regions, 16 million raster pixels, and 64 MiB of encoded output. Changing the document invalidates proposals; selection-only proposals also reject a changed selection. Settings remain locked until Start Over. Partial Create Slices updates the checkpoint revision and preserves the object selection so Play continues the original scope and skips all previously named regions. The original artwork is never moved or renamed.

AI detection currently requires the desktop app. The engine commands remain available through CLI/MCP/control:

- `slice.aiSnapshot {selectionOnly?, ignoreBackground?, ignoreShadows?}` returns document `uid`, `revision`, preview `rect`, spatial `regions` (including `sourceIds` for every component member) and `selectionIds`.
- `slice.applyAI {uid, revision, selectionOnly?, selectionIds?, regions}` adds named slices. The optional `preserveSelection:true` keeps the object selection (used by the player); the default selects the new slices. Regions contain `name`, `x`, `y`, `width`, `height` in document points. With selection scope, supply the snapshot's `selectionIds`.
- `slice.exportAI {uid, revision, selectionOnly?, selectionIds?, regions, ignoreBackground?, ignoreShadows?, format?, matchPreview?, scale?, folder?, createFolder?}` exports checked regions. An optional `candidateIndex` (0–63) supplies a stable export-number prefix across partial batches. Preserve the snapshot rows’ optional `sourceIds` to isolate all detected component members; omit them for rectangular crops of all artwork. `matchPreview:true` embeds a rendered image in SVG; the API default is false to preserve editable vectors. `createFolder` defaults true; false rejects a missing folder without creating it. Omitting `folder` returns base64 files. It does not change the document or the undo history.

Tests cover model-name validation, spatial separation and intact clipped groups, review/cancel/apply, document and selection guards, atomic creation and undo/redo, vector crop contents, transparent PNG dimensions, safe names and refusal to overwrite. An ignored live-model test accepts `VECTORCRAFT_SLICING_SVG` to name the first four candidates of a local multi-element user-owned fixture without committing it.
